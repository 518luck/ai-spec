# 快捷键系统落地计划

## 背景与现状

项目在 UI 和设计文档中多处「承诺」了快捷键,但绝大部分没有真实实现,存在用户按下去没反应的体验落差。已决策:**建完整快捷键体系**(不含「?」帮助面板与列表键盘导航,留作未来项),**命令面板保留 kbar**。

探索确认的关键事实:

- **已承诺未兑现**:3 个列表页按钮渲染了 `<Kbd>C</Kbd>` 但全仓零 handler(`src/pages/spec/personal/rules/ui/page.tsx:63`、`prompt/records/ui/page.tsx:158`、`prompt/drafts/ui/page.tsx:110`);kbar ⌘K 面板已生效但 UI 无任何入口提示;面板只有 `d d`/`t t` 两个主题命令。
- **⌘B 键位是自由的**:`src/shared/ui/sidebar.tsx` 的 Cmd+B 监听所在组件全仓零引用、永不挂载(shadcn 死组件);真侧边栏 `src/widgets/dual-sidebar/` 无键盘绑定。
- **死导出**:`CommandDialog`/`CommandShortcut`(command.tsx)、`DropdownMenuShortcut`(dropdown-menu.tsx)零引用;`KBar.tsx` 文件名违反 kebab-case。
- **react-use 的 useKey 不够用**(已读源码):只做 `event.key` 全等比较,无修饰键组合/焦点排除/enabled 选项 → 符合 hooks AGENTS.md 的自实现豁免条款。
- **kbar 源码核实**(InternalEvents.js / utils.js / tinykeys.js):`shouldRejectKeystrokes` 排除 input/textarea/contenteditable(覆盖 CodeMirror),但**不排除 base-ui 的 Menu/Dialog**;⌘K toggle 检查 `event.defaultPrevented` 且 tinykeys 挂 window 冒泡阶段 → CodeMirror keymap `return true` 可压过 kbar;序列超时 400ms;`useRegisterActions` 卸载自动解绑。
- **base-ui Dialog 默认聚焦弹窗内首个可聚焦元素** → ConfirmDialog 无输入框时原生 Enter 已可用,只有 `requireConfirmInput` 场景需要补。
- **`?create=1` 有同文件先例**:records 页已有「URL 参数 → 开弹窗 → `router.replace` 清参」模式(`records/ui/page.tsx:52-63` 的 `useRecordId`),照抄即可;list schema 非 strict(strip 未知键),路由层 page.tsx 无需改动。
- **坑**:base-ui Menu typeahead 吞字符键;工作台弹窗语义是「关闭即保存」(`prompt-workspace-dialog.tsx:134,163`,Esc = 保存并关闭,onSave 抛错阻止关闭);搜索框 input 无 ref;`IconButton` 的 `tooltip` prop 是 `string` 需放宽为 `ReactNode`。

## 架构总览:双轨制 + 单一键位表

```
src/shared/configs/hotkeys.config.ts   ← 键位唯一事实来源(纯数据)
        ↑                    ↑
  useHotkey(自实现)       kbar action
  UI 反射键/页面级单键      面板命令(导航序列、主题)
  C、/、⌘\               g r、g d…、d d、t t、⌘K(内建)
```

- **一个键位只有一个绑定所有者**(写入常量表注释):kbar action 带 shortcut 就绝不再用 useHotkey 绑同键。
- **C 键裁决**(采用 useHotkey 方案):kbar 的焦点排除不覆盖 base-ui 弹窗——编辑弹窗开着按 C 会叠开创建弹窗。故 C 由页面内 `useHotkey` 绑定(带 `enabled` 条件 + hook 内建模态抑制);kbar 面板的「新建」动作**不带 shortcut**,走 `?create=1` 导航,全局可用且不与 C 双触发。
- **不做中央注册表/作用域栈**:单人项目,作用域由组件挂载生命周期免费提供(hook effect 卸载、`useRegisterActions` 卸载均自动解绑);冲突靠常量表集中声明肉眼可查。避免过度设计。
- 编辑器内组合键走 **CodeMirror keymap**(不走全局 hook):命中 `return true` 自动 preventDefault,天然压过 kbar 与浏览器默认行为。

## 键位总表

| 键位 | 作用域 | 动作 | 绑定方式与位置 |
|---|---|---|---|
| `C` | 三个列表页 | 打开创建(弹窗/跳转) | useHotkey @ 各 page.tsx,`enabled` 挡弹窗已开 |
| `/` | 有搜索框的页面 | 聚焦搜索框 | useHotkey @ search-input-field.tsx 组件内 |
| `⌘\` | 全局(mod 键豁免焦点排除) | 折叠/展开侧边栏 | useHotkey @ dual-sidebar.tsx(⌘[/⌘] 是浏览器历史键不可用) |
| `⌘K` | 全局 | 唤起命令面板 | kbar 内建,不动 |
| `g r`/`g d`/`g g`/`g a`/`g s` | 全局序列 | 去收录库/草稿箱/规约库/AGENTS.md/设置 | kbar-actions.tsx(kbar 自带输入态排除) |
| `d d`/`t t` | 全局序列 | 主题切换(已有) | kbar-actions.tsx,shortcut 改从常量表取 |
| `⌘B`/`⌘I`/`⌘E`/`⌘K` | CodeMirror 聚焦 | 加粗/斜体/行内代码/链接 | formatKeymap @ markdown-editor(⌘K 压过 kbar 已核实可行) |
| `⌘⌥1`/`⌘⇧9` | CodeMirror 聚焦 | 一级标题/引用 | 同上 |
| `⌘↵`(`⌘S` 为别名) | 工作台弹窗 | **保存并关闭**(复用 handleClose) | CodeMirror `Prec.highest` keymap + 弹窗容器 onKeyDown 双层覆盖 |
| `Enter` | ConfirmDialog 的 requireConfirmInput 输入框 | 确认 | Input onKeyDown(无输入框场景原生已可用,不改) |

「面板内搜索提示词、选中即复制」(设计文档 P2):技术可行但含两个含糊点(kbar 模糊匹配需 hack keywords、列表 VO 无全文需二次请求),**本期不做**,先落静态动作验证 ⌘K 使用习惯。

## 文件改动清单

### 新建(4 个)

1. **`src/shared/configs/hotkeys.config.ts`** — 键位唯一事实来源(跟随 theme.config.ts 先例)。`HotkeyEntry = { combo?, kbarShortcut?, label }`,每条注明 owner;文件头 `!` 注释写死两条硬规则(单一所有者;kbar 单字母不排除 base-ui 弹窗,故单字母一律归 useHotkey)。
2. **`src/shared/hooks/use-hotkey.ts`** — 自实现 hook,`"use client"`。签名遵循项目 Options Object 规则:
   ```ts
   type UseHotkeyOptions = {
     combo: string;                      // "mod+b" | "c" | "/"
     onTrigger: (e: KeyboardEvent) => void;
     enabled?: boolean;                  // 默认 true
     allowInEditable?: boolean;          // 默认 false
     preventDefault?: boolean;           // 默认 true
   };
   const useHotkey = ({ ... }: UseHotkeyOptions): void
   ```
   要点:latest-ref 存 handler 避免重挂监听;`isComposing || keyCode === 229` IME 防护;`event.defaultPrevented` 先让行;**裸键(无 mod)做三重排除**——可编辑元素(`isContentEditable` 覆盖 CodeMirror)、弹出层(`closest('[role="menu"],[role="listbox"]')`)、**模态抑制**(`document.querySelector('[data-slot=dialog-content]')` 存在即不触发,dialog.tsx:69 所有弹窗带此标记);mod 组合键豁免排除(⌘\ 在输入框内也生效,VSCode 同款行为)。
3. **`src/shared/lib/format-hotkey.ts`** — token → 平台符号(`"mod+b"` → `⌘B`/`Ctrl+B`),供 Tooltip/Kbd 展示。
4. **`src/widgets/dual-sidebar/ui/command-entry.tsx`** — ⌘K 入口:`useKBar().query.toggle` + `Icons.search` + 「搜索命令」+ `<Kbd>⌘K</Kbd>`;`collapsed` 态退化为图标 + Tooltip。替换 `dual-sidebar.tsx:356-358` 的「底部固定栏」占位 div。

1. **地基**:hotkeys.config.ts → use-hotkey.ts + barrel → format-hotkey.ts → KBar 改名/换 Kbd → kbar-actions 接常量表 → 删三处死代码。
2. **编辑器批**(与 3 无依赖可并行):editor.ts keymap + markdown-editor 扩展与 onSubmitShortcut → quick-toolbar 提示 → 工作台 ⌘↵/⌘S → ConfirmDialog Enter。
3. **kbar 批**:导航 g 序列 + 新建动作 + records/drafts 的 `?create=1` effect → command-entry.tsx ⌘K 入口。
