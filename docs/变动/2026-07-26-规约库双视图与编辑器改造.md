# 2026-07-26 规约库双视图 + 规约编辑器改造

> 基线提交：`d7dceef`（feat: 预览使用滚动容器）
> 变动规模：12 改 + 7 增 + 2 删

## 一句话总览

规约库列表页从「只有表格」变成「表格 / 卡片双视图」（视图状态进 URL、切换带动效），顺手把卡片组件从提示词模块上升为 shared 公共组件；规约编辑页的 `Textarea` 换成项目的 markdown 编辑器（含快捷栏、浮层标题栏、双击改名）。

## 一、规约库列表：新增表格 / 卡片双视图

### 变动动机

列表之前只有表格一种形态，但规约正文是长文本，表格里只能看到一行 preview。收录页（prompt/records）已经有成熟的卡片形态，规约库复用同一套卡片即可，视图由用户自行切换。

## 四、规约编辑页：Textarea → markdown 编辑器

### 变动动机

规约正文是 markdown，之前只是个 `Textarea`，没有语法高亮、没有格式化快捷栏、没有预览。项目里已有 `features/markdown-editor`（提示词工作台在用），这里直接接上。

| 文件                                                    | 状态 | 改动内容                                                                                                                                                     | 为什么                                                                                                                                                                                                                          |
| ------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/pages/spec/personal/rules/ui/rule-editor-form.tsx`  | 改   | ① `Textarea` → `MarkdownEditor`，本层持有 `editorRef` 同时传给编辑器和 `QuickToolbar`                                                                          | `editorRef` 是 DOM 句柄，按 markdown-editor 的约定由编排层持有：编辑器挂 CodeMirror，快捷栏拿它执行格式化                                                                                                                          |
|                                                         |      | ② 顶部状态栏加 `QuickToolbar`，并用 `useMounted` 门控渲染                                                                                                      | 快捷栏顺序存在 localStorage，服务端取不到；挂载后再渲染，避免 hydration 不一致                                                                                                                                                    |
|                                                         |      | ③ 进页面 `useEffect` 调 `resetView()`                                                                                                                        | 编辑器运行态（`isPreview` / `activeFormats`）是 store 里的，不重置会带着上次残留的预览模式打开                                                                                                                                    |
|                                                         |      | ④ 本地 `extractTitle` 删掉，改从 `@/features/markdown-editor` 引入                                                                                             | 同一份"取正文首个非空行"逻辑已在 feature 里导出，去重                                                                                                                                                                            |
|                                                         |      | ⑤ 常驻的名称 `Input` 换成新的 `EditableName`：平时是纯文本标题（名称为空时顶上"创建规约 / 编辑规约"），双击或回车切输入框，失焦 / 回车提交、Esc 放弃；清空则恢复跟随正文首行 | 标题栏上一直摆着个输入框太重；同时"名称默认取首行、手动改过就脱钩"的规则保留，且现在清空名称能显式交还给首行接管                                                                                                                  |
|                                                         |      | ⑥ `TitlePageShell` 传 `scrollable={false}` + `floatingHeader`；内容区改 `min-h-0 flex-1 overflow-hidden`；编辑器底色透明、`.cm-scroller` 加 `px-6 pt-18`         | **必须关外层 ScrollArea**：CodeMirror 的 `height:100%` 依赖父级稳定高度，ScrollArea 的 viewport 会收缩到内容尺寸，导致虚拟滚动失效。底色改透明是因为状态栏是半透明渐变，压在另一种底色上会显脏；`pt-18` = 状态栏 `h-16` 再多 0.5rem，首行不被压住、上滚时文字从状态栏下穿过 |
| `src/features/markdown-editor/ui/markdown-editor.tsx`   | 改   | 新增 `editorClassName` prop，`cn("h-full text-sm", editorClassName)` 透传给 CodeMirror 根节点                                                                  | 编辑区的 padding 等布局应由调用方决定（本次规约页要 `px-6 pt-18` 让正文对齐浮层状态栏）。与已有的 `previewClassName` 对称；覆盖内置样式需加 `!`                                                                                    |
| `src/widgets/page-shell/ui/title-page-shell.tsx`        | 改   | 新增 `floatingHeader` prop（仅 `scrollable={false}` 生效）：容器加 `relative`，标题栏改 `absolute inset-x-0 top-0 z-10` + 从上到下的半透明渐变 + `backdrop-blur-sm` | 给"内部自管滚动"的编辑器用：标题栏不占布局高度，内容从页面顶端起算，滚动时正文从毛玻璃状态栏下方穿过。原有的两种模式（sticky 吸顶 / 固定占位）行为不变                                                                              |

## 五、遗留 / 待确认

- `?view=` 目前只服务规约库列表。若后续收录页也要双视图，`RuleView` / `parseRuleView` / `RuleViewToggle` 与 `lib/list-motion.ts` 这一套应一起上升到 `features` 或 `shared`。
- `ContentCard` 的容器样式（`aspect-4/3`、亮暗投影）仍是硬编码常量串；若第三处使用者有不同比例需求，再考虑开 prop。
