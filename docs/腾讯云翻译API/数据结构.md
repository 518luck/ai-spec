## BoundingBox

段落文本框位置：x，y代表左上顶点，width和height代表宽高

被如下接口引用：ImageTranslateLLM。

| 名称 | 类型 |  描述 |
|------|------|-------|
| X | Integer | <p>左上顶点x坐标</p><br/>示例值：0 |
| Y | Integer | <p>左上顶点y坐标</p><br/>示例值：0 |
| Width | Integer | <p>宽</p><p>单位：px</p><br/>示例值：10 |
| Height | Integer | <p>高</p><p>单位：px</p><br/>示例值：10 |

## Coord

坐标详细信息

被如下接口引用：ImageTranslateLLM。

| 名称 | 类型 | 必选 | 描述 |
|------|------|----------|------|
| X | Integer | 否 | X坐标<br/>示例值：10 |
| Y | Integer | 否 | Y坐标<br/>示例值：10 |

## RotateParagraphRect

段落文本旋转信息

被如下接口引用：ImageTranslateLLM。

| 名称 | 类型 | 必选 | 描述 |
|------|------|----------|------|
| Coord | Array of [Coord](#Coord) | 否 | 段落文本坐标 |
| TiltAngle | Float | 否 | 旋转角度<br/>示例值：1.0 |
| Valid | Boolean | 否 | 段落文本信息是否有效<br/>示例值：true |

## TransDetail

大模型图片翻译详情信息

被如下接口引用：ImageTranslateLLM。

| 名称 | 类型 |  描述 |
|------|------|-------|
| SourceLineText | String | <p>当前行的原文本</p><br/>示例值：你好 |
| TargetLineText | String | <p>当前行的译文</p><br/>示例值：hello |
| BoundingBox | [BoundingBox](#BoundingBox) | <p>段落文本框位置</p> |
| LinesCount | Integer | <p>行数</p><br/>示例值：1 |
| LineHeight | Integer | <p>行高</p><p>单位：px</p><br/>示例值：10 |
| SpamCode | Integer | <p>正常段落spam_code字段为0；如果存在spam_code字段且值大于0（1: 命中垃圾检查；2: 命中安全策略；3: 其他。），则命中安全检查被过滤。</p><br/>示例值：0 |
| RotateParagraphRect | [RotateParagraphRect](#RotateParagraphRect) | <p>段落文本旋转信息，只在valid为true时表示坐标有效</p> |
