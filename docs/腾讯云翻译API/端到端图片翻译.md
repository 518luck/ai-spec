## 1. 接口描述

接口请求域名： tmt.tencentcloudapi.com 。

提供18种语言的图片翻译服务，可自动识别图片中的文本内容并翻译成目标语言，识别后的文本按行翻译，后续会提供可按段落翻译的版本。

- 输入图片格式：png、jpg、jpeg等常用图片格式，不支持gif动图。
- 输出图片格式：jpg。

提示：对于一般开发者，我们建议优先使用SDK接入简化开发。SDK使用介绍请直接查看 5. 开发者资源 部分。

默认接口请求频率限制：1次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/551/15615)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/551/15615)，本接口取值：ImageTranslateLLM。 |
| Version | 是 | String | [公共参数](/document/api/551/15615)，本接口取值：2018-03-21。 |
| Region | 是 | String | [公共参数](/document/api/551/15615)，详见产品支持的 [地域列表](/document/api/551/15615#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Data | 是 | String | <p>图片数据的Base64字符串，经Base64编码后不超过 9M，分辨率建议600*800以上，支持PNG、JPG、JPEG格式。</p><br/>示例值：/9j/4QlQaHR0c...N6a2M5ZCI |
| Target | 是 | String | <p>目标语言，支持语言列表：</p><ul><li>中文：zh</li><li>繁体（中国台湾）：zh-TW</li><li>繁体（中国香港）：zh-HK</li><li>英文：en</li><li>日语：ja</li><li>韩语：ko</li><li>泰语：th</li><li>越南语：vi</li><li>俄语：ru</li><li>德语：de</li><li>法语：fr</li><li>阿拉伯语：ar</li><li>西班牙语：es</li><li>意大利语：it</li><li>印度尼西亚语：id</li><li>马来西亚语：ms</li><li>葡萄牙语：pt</li><li>土耳其语：tr<br>-</li></ul><br/>示例值：en |
| Url | 否 | String | <p>输入图 Url。 使用Url的时候，Data参数需要传入&quot;&quot;。 图片限制：小于 10MB，分辨率建议600*800以上，格式支持 jpg、jpeg、png。</p><br/>示例值：https://xxx.com/image.jpg |
| Mode | 否 | Integer | <p>调用模式。</p><p>枚举值：</p><ul><li>0： 端到端图片翻译大模型pro版</li><li>1： 端到端图片翻译大模型lite版</li></ul><p>默认值：0</p><br/>示例值：0 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | String | <p>图片数据的Base64字符串，输出格式为JPG。</p><br/>示例值：iVBORw0KGgoAAAANSUhEUgAAAdkAAABPCAYAAACnD7%252FoAAAAAXNSR0IArs4c6QAAAARnQU1BAACxjwv8YQUAAAAJcEhZcwAADsMAAA7DAJ......CCyAAAAwCQgsgAAAMAkILIAAADAJCCyAAAAwCQgsgAAAMAkILIAAADAFJblX8%252F8oMOWYN6nAAAAAElFTkSuQmCC|
| Source | String | <p>原文本主要源语言。</p><br/>示例值：en|
| Target | String | <p>目标翻译语言。</p><br/>示例值：zh|
| SourceText | String | <p>图片中的全部原文本。</p><br/>示例值：hello|
| TargetText | String | <p>图片中全部译文。</p><br/>示例值：你好|
| Angle | Float | <p>逆时针图片角度，取值范围为0-359</p><br/>示例值：90.0|
| TransDetails | Array of [TransDetail](/document/api/551/17233#TransDetail) | <p>翻译详情信息</p>|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|
