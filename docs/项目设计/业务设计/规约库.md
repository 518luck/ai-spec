# 规约库

## 定位

> **为 AI 编写约束规则的原子库，是 AGENTS.md 的素材源。**

规约库存储一条条原子化的约束规则（react 的函数组件风格、go 的 error 处理、短剧的转场手法……），AGENTS.md 引用这些规则组合成系统化的整体。

- 规约库 = 原子规则的「**零件库**」
- AGENTS.md = 把零件装配成机器的「**车间**」

---

## 一、三层结构

```
领域空间（顶层，物理隔离）
└─ 文件夹（空间下一层，分类）
   └─ 规则（叶子，原子约定）
       └─ 标签（贯穿文件夹检索）
```

| 层           | 职责                                     | 关键特性                                                   |
| ------------ | ---------------------------------------- | ---------------------------------------------------------- |
| **领域空间** | 物理隔离不同世界（代码 / 创作 / 智能体） | 顶层平级，**标签无法穿透** —— 规则的「家」固定在此         |
| **文件夹**   | 空间内分类                               | 一层不嵌套（react / go / typescript）                      |
| **标签**     | 空间内贯穿检索                           | 聚合当前空间里所有文件夹中带同一标签的规则，**出不了空间** |
| **规则**     | 一条原子约束                             | 标题 + 正文，长度可短可长                                  |

### 为什么是这三层

- **空间隔离**保证基石不混乱：一条 react 规则永远在代码空间，不会漂泊到创作空间。
- **文件夹**解决空间内的分类，一层够用，嵌套会增加心智负担。
- **标签**解决「同一主题跨文件夹」的检索，但不破坏空间隔离（找得到，归属不变）。

---

## 二、与 AGENTS.md 的关系（核心联动）

> **AGENTS.md 引用规约库的规则，不是复制。**

- 规则在规约库里只有一份，AGENTS.md 通过**引用**挂载到自己的章节树中。
- 规则改了，所有引用它的 AGENTS.md **自动更新**。
- AGENTS.md 的文件夹树 + 章节结构，对应规约库规则的「装配方式」。

```
规约库（原子）                 AGENTS.md（系统）
代码空间                       React 项目规范/
└─ react/                      ├─ 组件/
   ├─ 函数组件风格      ◄──────┤  └─（引用：函数组件风格）
   ├─ props 约定        ◄──────┤  └─（引用：props 约定）
   └─ 命名规则          ◄──────└─ 命名（引用：命名规则）
```

## 三、与 Prompt 收录的区别

|              | Prompt 收录              | 规约库                       |
| ------------ | ------------------------ | ---------------------------- |
| **单元性质** | 独立提示词（一次性指令） | 原子规则（长期约束）         |
| **用途**     | 复制即用，用完即弃       | 被 AGENTS.md 引用，长期生效  |
| **组织**     | 扁平文件夹横向归类       | 领域空间 + 文件夹 + 标签三层 |
| **去向**     | 聊天框                   | AGENTS.md                    |

## 四、界面设计思路

### 首页 Table

1. 需要注意**操作的大小位置**。
2. 需要标明**文件夹的来源**。
3. 在标题上方引入 `help`：
   - **标签说明** —— 可贯穿文件夹，不能贯穿领域。
   - **领域说明** —— 声明自己是一个绝对隔离的空间。
4. Table 子项甚至可以不要正文预览，但**标签必须尽可能展示**。

### 领域与文件夹图标

- **领域**：看看可不可以加图标。
- **文件夹**：如果领域能加，文件夹应该也可以内嵌图标。

> 💡 此项为**优化项**，非必需。

### 详情界面

- 顶部需要一个**下拉框**，查看该规则**被谁引用了**。
