## 草稿箱是什么

草稿箱是你的「便签纸」：正在和 AI 对话时冒出一个好用的提示词，不用停下来想标题、写描述、打标签——按下 `C`，粘贴进去，关掉，继续工作。

草稿会自动取内容的第一行作为展示标题，没有合适首行时显示为「无标题草稿」。你不需要为一条草稿做任何整理工作。

<Callout title="核心理念" type="info">
  记录的摩擦越低，你越愿意记。草稿箱把「保存一条提示词」压缩到粘贴一次的成本。
</Callout>

## 什么留草稿，什么进收录

草稿箱和收录库是双轨分工，判断标准很简单：

| 场景 | 去处 |
| ---- | ---- |
| 临时想到、还没验证效果的提示词 | 草稿箱 |
| 只用一两次、用完可能就删的片段 | 草稿箱 |
| 反复使用、已经打磨成型的提示词 | 收录库 |
| 需要版本历史、标签、收藏管理的资产 | 收录库 |

一句话：**草稿是暂存，收录是资产**。草稿随时可删、无需整理；收录有标题、标签、收藏、版本历史和使用统计。当一条草稿被你反复复制使用，就是它该「转正」的时候了。

收录库的完整能力见 [收录库指南](/docs/guides/records)。

## 记录与编辑

### 快速新建

在[草稿页](/spec/personal/prompt/drafts)按 `C`，或点击右上角「新建草稿」按钮，即可打开创建弹窗。也可以随时用 `⌘K` / `Ctrl+K` 打开命令面板，执行「新建草稿」。

### 关闭即保存

点击草稿卡片上的编辑按钮打开编辑弹窗。编辑器没有单独的「保存」流程——**关闭弹窗时自动保存**：

- 直接关闭弹窗，有改动就保存，没改动就不打扰
- `⌘↵` / `Ctrl+Enter` 或 `⌘S` / `Ctrl+S` 保存并关闭
- 内容为空时不会保存——新建直接关闭，编辑也不会覆盖原有内容

改完就关，不用惦记保存这件事。

## 升级为收录

当一条草稿值得长期保留，点击卡片上的**「复用」**按钮，把它升级进收录库：

1. 在弹出面板中选择目标资源（当前支持收录库）
2. 为它挑选文件夹和标签，完成归类
3. 可勾选「连带删除草稿」——升级后原草稿自动清理，避免两边重复
4. 点击「确认复用」，内容原样进入收录库

不勾选删除时，原草稿保留不动，你可以继续把它当便签用。

<Callout title="提示" type="info">
  复用会带走草稿的完整内容和标题，进入收录库后你可以随时调整文件夹与标签，并开始积累版本历史。
</Callout>

## 日常管理

草稿虽然轻量，常用的管理动作一样不少：

- **一键复制**：点击卡片任意位置即复制全文到剪贴板，无需打开详情
- **搜索**：按 `/` 聚焦搜索框，支持按标题或内容搜索
- **文件夹归类**：草稿也可以放进文件夹，页面顶部可按文件夹筛选
- **删除**：卡片上的删除按钮带二次确认；删除后无法恢复，重要内容请先复用进收录库
