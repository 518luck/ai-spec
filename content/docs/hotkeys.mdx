---

Prompt Shelf 的快捷键在 mac 上使用 `⌘`（以及 `⌥`、`⇧`），在 Windows / Linux 上对应 `Ctrl`（以及 `Alt`、`Shift`）。

<Callout title="随手可查" type="info">
  按 `⌘K` / `Ctrl+K` 打开命令面板，常用命令旁边会直接标注对应的快捷键，不必刻意背记。
</Callout>

## 全局

任意页面都可使用：

| 快捷键（mac） | Windows · Linux | 作用 |
| --- | --- | --- |
| `⌘K` | `Ctrl+K` | 打开命令面板 |
| `⌘\` | `Ctrl+\` | 折叠 / 展开侧边栏 |

## 命令面板序列键

序列键是「连按」：快速先后按下两个字母（如先按 `G` 再按 `R`），mac 与 Windows / Linux 按法相同。输入框聚焦时不会误触发。

| 快捷键（mac） | Windows · Linux | 作用 |
| --- | --- | --- |
| `G R` | `G R` | 前往收录库 |
| `G D` | `G D` | 前往草稿箱 |
| `G G` | `G G` | 前往规约库 |
| `G A` | `G A` | 前往 AGENTS.md |
| `G S` | `G S` | 前往设置 |
| `D D` | `D D` | 切换明暗模式 |
| `T T` | `T T` | 循环切换色彩主题 |

## 列表页

在[收录库](/spec/personal/prompt/records)、草稿箱、规约库的列表页可用。光标在输入框或编辑器内时，单字母键不会触发。

| 快捷键（mac） | Windows · Linux | 作用 |
| --- | --- | --- |
| `C` | `C` | 新建（打开创建弹窗或跳转创建页） |
| `/` | `/` | 聚焦当前页的搜索框 |

## 编辑器格式化

在 Markdown 编辑器的输入区聚焦时可用，选中文字后按键即可套用格式：

| 快捷键（mac） | Windows · Linux | 作用 |
| --- | --- | --- |
| `⌘B` | `Ctrl+B` | 加粗 |
| `⌘I` | `Ctrl+I` | 斜体 |
| `⌘⌥1` | `Ctrl+Alt+1` | 一级标题 |
| `⌘⇧9` | `Ctrl+Shift+9` | 引用 |
| `⌘E` | `Ctrl+E` | 行内代码 |
| `⌘K` | `Ctrl+K` | 插入链接 |

<Callout title="编辑器内的 ⌘K" type="warn">
  输入区聚焦时，`⌘K` / `Ctrl+K` 是「插入链接」，不会打开命令面板；离开编辑器后恢复为打开命令面板。
</Callout>

## 编辑弹窗

提示词编辑弹窗遵循「关闭即保存」：无论哪种方式关闭，内容都会先保存。

| 快捷键（mac） | Windows · Linux | 作用 |
| --- | --- | --- |
| `⌘↵` | `Ctrl+Enter` | 保存并关闭（`⌘S` / `Ctrl+S` 同效） |
| `Esc` | `Esc` | 保存并关闭 |
| `Enter` | `Enter` | 删除确认弹窗中确认删除 |
